# Verification

What makes a check worth having; `testing.md` is what to write.

- **Measure the artefact, not the configuration.** Match the instrument.
- **One decision, one place.** The hidden copy wins; test that copies agree.
- **An unset value is not a safe value.** Count explicit correct values, not missing wrong ones.
- **A call never made passes every unit test.** Assert the user's path reaches it.
- **A check that keeps saying "clean" locates your blind spot.**
- **Every check needs a negative control.**
