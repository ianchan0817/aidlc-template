# Retro

1. **Gather** — `git log --since="2 weeks ago" --oneline --all`, `git shortlog -sn`, read `.claude/memory/progress.md`
2. **Analyze** — what went well (specific), what went wrong (root cause), what was slow
3. **Improve agents** — if pattern repeated 2+ times: update `.claude/agents/[agent].md`, note in memory
4. **Update memory** — clear completed, move upcoming, log decisions, clean resolved issues
