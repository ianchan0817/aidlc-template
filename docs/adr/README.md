# Architecture decision records

One file per decision: `ADR-NNN-kebab-title.md`, format in
`aidlc/examples/adr.md`. Records **this project's** decisions — the template's own
are in `.maintainer/adr/`, which adoption deletes, because inheriting someone
else's accepted decisions as your own is how a project ends up defending a
constraint nobody chose.

Write one when a choice is expensive to reverse, constrains later work, or will
be asked about again in six months. Not for every judgement call.
